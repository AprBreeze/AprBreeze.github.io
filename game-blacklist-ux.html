UX Redesign - Tom Clancy's Splinter Cell: Blacklist体验重设计 · 细胞分裂：黑名单

UI/UX Design - 2025界面与体验设计 · 2025

Project Overview项目概览

In the competitive gaming market now, great content is no longer enough. To compete for users' attention, mobile games have been mastering user experience to minimize the friction for users during crucial stages like onboarding, core gameplay, etc, yet many PC titles still suffer from UX issues.在如今竞争激烈的游戏市场里，内容本身已经不够。为了抢注意力，手游把用户体验做得很细，尽量减少新手引导、核心玩法等关键节点的摩擦；但许多 PC 作品仍有明显的体验问题。

My redesign project of the classic Tom Clancy's Splinter Cell: Blacklist aims to expose these legacy issues, sharpening my awareness of UX problems that hinder player engagement.这次对经典作《细胞分裂：黑名单》的重设计，就是要把这些遗留问题摆出来，也让我更清楚哪些体验问题会挡住玩家投入。
