Project Overview项目概览

This was my first entry into the Ubisoft NEXT Level Design Competition in 2022. The challenge was to design a stealth action game level with a strong theme, immersive environments, visual references, and clear presentation.这是我 2022 年第一次参加育碧 NEXT 关卡设计大赛。题目是设计一张潜行动作关卡，要有明确主题、沉浸的环境、视觉参考，以及清楚的表达。

The level had to combine gameplay elements provided by Ubisoft to create an engaging and enjoyable player experience, while supporting multiple approaches and allowing players to approach objectives from all directions.关卡需要把育碧提供的玩法元素组合起来，做出有吸引力、好玩的体验，同时支持多种切入方式，并让玩家可以从各个方向接近目标。

Design Problem设计问题

🎯 The goal was to design a stealth action game level with a strong theme, immersive environments, visual references, and a clear presentation.🎯 目标是设计一张潜行动作关卡，要有明确主题、沉浸的环境、视觉参考，以及清楚的表达。

The level must combine gameplay elements provided by Ubisoft to create an engaging and enjoyable player experience.关卡必须组合育碧提供的玩法元素，做出有吸引力、好玩的体验。

📋 Additional Requirements:📋 额外要求：

  • 🔄 Support multiple approaches to the objective🔄 支持多种切入方式接近目标
  • 🧭 Allow players to approach the level from all directions 🧭 让玩家可以从各个方向进入关卡

Started from ideating the pillar experience从构思体验支柱开始

🎨 Initial Ideation🎨 初期构思

  1. 1. Ideate narrative for player experience and theme1. 围绕玩家体验和主题构思叙事
  2. 2. Define the gameplay plot and experience plot
    • Gameplay plot → what player plays
    • Experience plot → what player feels    2. 定义玩法情节与体验情节
    • 玩法情节 → 玩家在玩什么
    • 体验情节 → 玩家感受到什么
  3. 3. Ideate an interesting theme and setting for the mission3. 为任务构思有趣的主题与场景设定
  4. 4. Start to piece together gameplay elements into the level4. 开始把玩法元素拼进关卡

Support main exp with proper gameplay and pacing用合适的玩法与节奏支撑主体验

🎭 Experience Design🎭 体验设计

  1. 1. Think about the feeling of each area1. 思考每个区域的感受
  2. 2. Determine the main gameplay beat to convey the feeling
    • Puzzle? Combat encounters? Key & lock?    2. 确定用来传达感受的主要玩法节拍
    • 解谜？战斗遭遇？钥匙与锁？
  3. 3. Multiple Approaches
    • Iterate on creating alternatives to create options and replayability for players    3. 多种切入方式
    • 反复打磨备选路线，给玩家选择空间和重玩价值

Design Challenges设计挑战

🤔 Key Questions I Faced:🤔 我面对的关键问题：

  • ❓ How to make sure different approaches all have enjoyable experiences?❓ 如何保证不同切入方式都有好玩的体验？
  • 🔑 How to make a key&lock-type puzzle intuitive (let players know which lock to unlock)?🔑 如何让钥匙与锁类解谜更直观（让玩家知道该开哪把锁）？
  • 📋 How to make sure my approaches are clearly conveyed through my presentation?📋 如何确保我的切入方式能在演示中清楚地传达？

Design Solutions设计方案

💡 My Approach to Solving These Challenges:💡 我应对这些挑战的做法：

  • ⚖️ Place gameplay elements that have a similar level of engagement for different approaches⚖️ 为不同切入方式放置参与感相近的玩法元素
  • 📖 Adding narrative elements like documents to convey the use of keys📖 加入叙事元素（如文件）来说明钥匙的用途
  • 🗺️ Creating separate approaching paths walkthrough for the 3 alternatives🗺️ 为 3 条备选路线分别做接近路径流程说明
  • 🎮 Additional insight: Adding gameplay elements in between to make key&lock-type puzzles more interesting🎮 额外心得：在钥匙与锁之间插入玩法元素，让这类解谜更有趣

Outcome & Reflection结果与反思

I created a detailed level design document and reference sheet for a stealth mission in a competition, sharpening my creative problem-solving and gaining practical experience in effective level design.我为这次比赛的潜行任务做了详细的关卡设计文档和参考页，锻炼了创造性问题解决能力，也积累了有效关卡设计的实践经验。

📚 Key Takeaways from Feedback and Self-Reflection:📚 来自反馈与自我反思的关键收获：

  • 📄 The document has to be cleaner and concise📄 文档需要更干净、更简洁
  • 🏗️ Space arrangement can be more place-like and fitting theme🏗️ 空间布置可以更像真实场所，并更贴合主题
  • ✍️ Try concise documentation to level design✍️ 尝试用更简洁的文档做关卡设计
  • 🎬 Mission description needs to be more vivid - Improve presentation🎬 任务描述需要更生动 - 改进表达
  • 🗺️ Top-down Map presentation needs more work to showcase details than paragraphs🗺️ 俯视图呈现还需要加强，用图展示细节，而不是靠大段文字
  • 📏 Consider the metric of the level - Include a grid for reference📏 考虑关卡尺度 - 加入网格作为参照

🎯 Competition Result🎯 比赛结果

This entry was my first entry into the competition. It did not get into the final phase (top 10), but it was a great exercise to put theory into practice.这是我的首次参赛。没有进入最终阶段（十强），但它是一次把理论落到实践的很好练习。

🚀 Moving Forward🚀 接下来

As I continue learning level design knowledge, I will be participating in future competitions! This experience taught me the importance of clear documentation, concise presentation, and practical application of design principles.在继续学习关卡设计的同时，我也会继续参加未来的比赛！这次经历让我更明白清晰文档、简洁表达，以及把设计原则真正用起来有多重要。
